# Advanced Bioelectronics — Website V1

A simple static company landing page designed for GitHub Pages.

## Files
- `index.html` — single-page site
- `style.css` — responsive styling

## Publish with GitHub Pages

1. Upload `index.html` and `style.css` to the root of:
   `sunyunpark/advanced-bioelectronics`
2. Commit the files to the `main` branch.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. Save.

The project site should then be available at:
`https://sunyunpark.github.io/advanced-bioelectronics/`

## Before public launch
- Replace `contact@example.com` in `index.html`.
- Review all technology claims and wording.
- Replace the temporary `AB` text mark if/when a final logo is selected.
- Add the final corporate name only after incorporation.
- Add a custom domain later if desired.

## Notes
The page uses relative asset paths (`./style.css`) so it works correctly as a GitHub Pages project site.
